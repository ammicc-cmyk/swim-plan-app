# Профиль пловца

## Базовые данные

- Пол/возраст: женщина, 43 года
- Уровень на старте: начинающая
- Бассейн: 50 м, без разделителя на 25 м
- Стиль-фокус: кроль (основной), брасс и спина — для разнообразия
- Частота тренировок: не зафиксирована явно в диалоге (предполагалось
  2–3 раза в неделю на старте) — уточнить и внести сюда

## Прогресс навыков (на момент последнего handover)

- Проплывает 50 м без остановки, но медленно
- Дыхание: ритм каждые 3 гребка — отрабатывается стабильно
- Билатеральное дыхание — предложено, не протестировано отдельно от
  общего блока
- Координационно сложные drills (zipper, скаллинг) — пока не даются,
  отложены до укрепления среднего уровня

## Журнал тренировок

### Тренировка N (месяц занятий: ~1)
- Объём: 700–800 м, все упражнения кратны 50 м
- Инвентарь: доска, колобашка — расположен на старте
- Выполнено: разминка, ноги доска (кроль/брасс), single-arm с колобашкой,
  catch-up, fist, основной кроль, брасс, спина, заминка
- Резерв: 2×50 основной кроль — выполнен полностью
- Фидбэк: всё выполнено успешно

### Тренировка N+1
- Изменения по плану N: убраны ноги брасс (по факту — организационная
  причина, инвентарь не на той стороне, выяснено позже); single-arm с
  колобашкой заменена на "3 удара на груди / 3 на спине" (переключение)
- Резерв: выполнен полностью
- Фидбэк: план прошёл хорошо

### Тренировка N+2 (предложен, не проведён)
- Попытка ввести новые drills: zipper, скаллинг (продвинутый уровень)
- Фидбэк: «сложно» — оба упражнения не пошли, тренер вернулась к
  предыдущему рабочему плану (с брасс-ногами вместо zipper/скаллинга)
- Открытый вопрос: «сложно» относится к этим двум упражнениям конкретно
  или к тренировке в целом — не уточнено, зафиксировать в следующей сессии

## Что внести в приложение при первом запуске

- Форма/структура для добавления новой записи в журнал после каждой
  тренировки: объём, список упражнений, что убрано/заменено и почему,
  общий фидбэк.
- Поле "отложенные упражнения" с датой последней неудачной попытки —
  для правила "не предлагать 1-2 тренировки подряд" из PLAN_RULES.md.
